# Наборы правил

Действующие правила World of Warcraft пока не подключены. `rules.Load("blizzard")` возвращает пустой каталог: без подтверждённого патча и проверенного эталона анализ показывает `Unknown`.

`retail/synthetic-v1.json` — отдельная локальная демонстрация алгоритмов для вымышленных данных с патчем `synthetic-demo-v1`. Идентификаторы предметов, зачарований, комплекта и талантов синтетические. Поле `review_status=approved` означает только проверку согласованности этой локальной модели. Оно не подтверждает правила реального WoW. Набор доступен исключительно в режиме `fixture` и не применяется к Blizzard-данным.

Синтетическая матрица объявляет голову, плащ и запястья подходящими для демонстрационного зачарования. Это не утверждение о применимости зачарований в игре. `enchantments:null` даёт `Unknown`, подтверждённый пустой список — `Warning`, совместимое зачарование — `OK`. Другие синтетические предметы явно исключены из проверки.

Синтетический комплект содержит два конкретных предмета (голова и плечи) и один порог 2. Только для этой вымышленной модели подтверждено, что достаточно числа надетых частей (`item_count_only=true`). Без этого утверждения алгоритм не выводит активность бонуса из количества предметов. Две наблюдаемые части показываются как `Info`; явная цель для сборки в демонстрации не задана. Неподдержанный предмет с тем же ID комплекта делает вывод неизвестным, а не уменьшает число частей ради предупреждения.

Синтетический эталон талантов знает два узла и одну допустимую альтернативу. Неполные узлы, неподтверждённый активный набор, несовпадающая специализация или дерево дают `Unknown`. Различие с эталоном без отдельного ограничения — `Info`, а не автоматически ошибка игрока.

Для нового реального набора нужны точный патч/класс/специализация/контент, применимый сезон, версия каждого алгоритма, актуальные ссылки, дата и ответственный за проверку. JSON загружается строго: неизвестные поля, дубли свойств, дубли/пересечения активных контекстов, невалидные идентификаторы и неполная provenance отклоняются. SHA-256 фиксирует всё содержимое набора; общий digest каталога также включает версию механизма и используется при кешировании.
