# Источники и границы проверки

Дата подготовки: 30 октября 2026 года.

Основной источник требований — [приложенная архитектура](../architecture/v1.0.md), принятая пользователем. Эта спецификация уточняет этап 1 и не объявляет согласованными ещё не выбранные эксплуатационные параметры.

| Источник | Для чего используется | Что проверено |
| --- | --- | --- |
| [OpenAPI 3.1.1](https://spec.openapis.org/oas/v3.1.1.html) | Формат контракта OpenAPI 3.1 и JSON Schema | Первичная спецификация доступна; файл проекта использует 3.1.0 |
| [RFC 9110](https://datatracker.ietf.org/doc/html/rfc9110) | Семантика HTTP, 202 и Retry-After | Первичный текст доступен; 202 не обещает успешное выполнение задачи |
| [PostgreSQL: SELECT](https://www.postgresql.org/docs/18/sql-select.html) | Блокировки строк и SKIP LOCKED для очереди | Первичная документация доступна; проверка конкурентной очереди требует реального PostgreSQL |
| [Blizzard: официальный пример Client Credentials](https://github.com/Blizzard/node-signature-generator) | Подтверждение серверного OAuth-подхода | Репозиторий Blizzard доступен; это пример, а не текущий контракт всех полей Retail |
| [Battle.net Profile APIs](https://community.developer.battle.net/documentation/world-of-warcraft/profile-apis) | Будущие summary/equipment/statistics/specializations fixtures | Портал не предоставил читаемое содержимое при проверке; live schema и ответы не подтверждены |
| [Battle.net Game Data APIs](https://community.developer.battle.net/documentation/world-of-warcraft/game-data-apis) | Будущий контракт каталога realm | Доступна только оболочка страницы, не проверенные поля актуального ответа |
| [Battle.net OAuth guide](https://community.developer.battle.net/documentation/guides/using-oauth) | Итоговые OAuth URL/параметры | Полный текст не получен; сверить при подключении credentials |
| [PGlite](https://pglite.dev/docs/) | Изолированная проверка проекта DDL без запуска сервера | Встроенный PostgreSQL в памяти; не замена проверке блокировок и production-миграции |

Игровые данные EU/US и OAuth без credentials не запрашивались. Все будущие игровые примеры в тестовой матрице синтетические, пока отдельно не зафиксированы реальные обезличенные fixtures. Из этих документов нельзя заключить, какой патч или сезон сейчас актуален, какие слоты допускают зачарования и какой билд является эталонным.

Требование внутренней политики «не старше 30 дней» наследуется из принятой архитектуры и выбрано консервативно. Актуальная юридическая редакция условий Blizzard, разрешённые способы перепроверки и удаления, условия Warcraft Logs и возможность Raider.IO этим этапом не подтверждены. Их проверка относится к подготовке публичного запуска; текущие документы не используют сторонний пересказ условий как доказательство действующего разрешения.
