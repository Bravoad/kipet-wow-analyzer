# ADR-0001: Базовая архитектура v1.0

Дата: 30 октября 2026 года. Статус: **принято**.

Основание: пользователь приложил [архитектуру v1.0](../architecture/v1.0.md) и ответил «Утверждаю». Исходный текст сохранён без изменений; его формулировки о будущей реализации отражают состояние на момент подготовки.

Принимаем Go API и независимые Go workers в модульном монолите, React + TypeScript, PostgreSQL как источник истины, Redis для кеширования и распределённых ограничителей. Долговременная очередь размещается в PostgreSQL. Публичный просмотр не требует учётной записи. Начальные регионы — EU и US, интерфейс — русский и английский.

Blizzard — основной источник профилей. Warcraft Logs используется на последующих этапах для доступных публичных отчётов. Raider.IO отключён до отдельного решения о допустимости интеграции. Отсутствие достоверных данных или актуальных правил явно показывается пользователю; универсального балла качества игрока в MVP нет.

Следующий результат — спецификация MVP: модели, SQL-схема, OpenAPI, интерфейсы, первые правила и сценарии приёмки. Написание приложения и публичное развёртывание в это решение не входят. [Спецификация MVP](../mvp/specification.md) уточняет архитектуру для этапа 1; её эксплуатационные значения помечены как проектные настройки, а не отдельные утверждения пользователя.

Следствия: HTTP-обработчики используют прикладные сервисы; внешние провайдеры вызываются workers. Корректность, дедупликация заданий и запрет выдачи недействительных данных не зависят от доступности Redis. Правила анализа версионируются по контексту. Смена имени, сервера или внешнего ID не служит доказательством тождества персонажей.
