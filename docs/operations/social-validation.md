# Этап 5: гильдии, сравнение и JSON-экспорт

1 ноября 2026 года. Локальный API 0.5.0, без публичной публикации и без реальных Blizzard credentials.

## Реализованное поведение

Раздел «Гильдии» принимает регион EU/US, сервер из каталога и канонический slug гильдии. Профиль и состав собираются worker через отдельную долговременную очередь. API не обращается к Blizzard напрямую. Поддержаны дедупликация, lease/fencing, heartbeat, ограниченные попытки, Retry-After, карантин 403, удаление при обязательном 404 и предельное хранение 30 дней. Свежесть состава — 60 минут. Отрицательная HMAC-запись действует пять минут.

Worker сохраняет состав и продолжает постановку участников пакетами до 50, с курсором в PostgreSQL. Он использует общую очередь персонажей, её лимит, cooldown и dedup. Успех задания гильдии означает завершение постановки участников, а не наличие всех их профилей. Локальное перечитывание сводки показывает новый охват без принудительного обхода cooldown.

Сводка показывает число подтверждённых профилей относительно состава, fresh/stale/pending/unavailable, средний и медианный item level с размером выборки, классы из состава, наблюдаемые специализации, подтверждённые роли, факты об экипировке и охват прогресса. Данные профиля связываются с участником по региону, серверу, имени и provider ID. Совпадение имени в боевом логе не связывает личности. Неизвестная роль остаётся неизвестной. Количество пустых списков зачарований не объявляется количеством ошибок; замечания считаются только по применимому проверенному ruleset, иначе `null`.

Сравнение принимает от одного до пяти разных персонажей. Один пакетный SQL-запрос читает текущие снимки; каждая секция проходит ограничения публикации и собственных сроков. Недоступный участник не скрывает разрешённые данные остальных. Сопоставимость патча, класса/специализации и собственного сезона Mythic+ показана отдельно. Боевые DPS/HPS между персонажами не сравниваются без подтверждённого контекста боя. Общий балл игрока не рассчитывается.

RU/EN интерфейс поддерживает фильтры состава и переход к сравнению выбранных участников одной специализации. JSON-экспорт делает новый GET анализа гильдии либо POST сравнения и проверяет допустимый статус и deadline перед скачиванием. У гильдии дополнительно совпадают UUID и версия состава. Экспорт не читает старый браузерный кеш как источник разрешения.

## Синтетический пример

`eu / гордунни / kipet-lab` — вымышленная **Synthetic Kipet Laboratory**. Состав: Кипет, Ледник и Пропавший. Первые два имеют подтверждённые профили одной специализации с item level 278 и 270; третий получает 404. Ожидаемый охват — **2 / 3**, mean/median — **274**, недоступных — **1**. Роли неизвестны, сезон и патч явно синтетические. Эти данные не описывают реальную гильдию или игроков.

## Проверки

- `go test ./... -count=1` с реальным PostgreSQL и `go vet ./...`: пройдены. Миграции 0001–0008, последовательные откаты, выравнивание batch-результатов, HMAC-negative, карантин и сроки выдачи проверены.
- Linux amd64 `go test -race ./... -count=1` с PostgreSQL: пройден. Тест состава из 120 участников подтверждает пакеты 50/50/20, сохранение курсора после потери lease и запрет записи прежним владельцем.
- 23 frontend-теста и TypeScript/Vite production build: пройдены. Новые проверки охватывают границы и дубликаты сравнения, некорректный URL, Unicode slug, привязку версии состава, выбор одной специализации и deadline экспорта.
- OpenAPI 3.1 версии 0.5.0: 21 маршрут, спецификация валидна. 53 HTTP-ответа работающего приложения через nginx соответствуют схемам, включая сводку 2/3, mean/median, частичную недоступность и ограничения сравнения.
- Docker build/up: пройден, миграция 0008 применяется перед API/worker. Скачанные браузером JSON гильдии и сравнения содержат ожидаемые 2/3 профиля и два элемента сравнения.
- Браузер: фильтры класса/специализации, выбор пары и переход к сравнению, раскрытие характеристик, RU/EN, дубликаты и предел пяти строк проверены. На ширине 360 px document width — 345 px с учётом полосы прокрутки; таблица шириной 790 px остаётся внутри своего прокручиваемого блока. Ошибок и предупреждений приложения в консоли не обнаружено. Временный размер экрана сброшен.
- 68 локальных ссылок, YAML Compose/CI и побайтовое совпадение утверждённой архитектуры с исходным вложением: проверены.

Адаптер Blizzard проверен локальным HTTP-сервером на нормализацию, привязку идентичности, неизвестный состав и ошибки источника. Это не приёмка текущего live-контракта Blizzard. Для неё нужны credentials и обезличенные реальные ответы. Нагрузочная квалификация, удалённый CI и публичный production security-аудит остаются работой следующего этапа.
