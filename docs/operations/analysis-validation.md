# Этап 2: объяснимый анализ

30 октября 2026 года. Локальная версия API 0.2.0, без публикации в интернете.

## Реализовано

Независимый Rule Engine принимает неизменяемый нормализованный снимок и явный контекст. Три алгоритма — `GEAR_MISSING_ENCHANT`, `GEAR_SET_BONUS`, `TALENT_BUILD_DIFF` — возвращают применимость, исход, качественную уверенность, причину, параметры локализации и доказательства с путями к данным. Отсутствие данных не превращается в предупреждение об ошибке игрока. Универсального балла, BiS и оценки потери DPS нет.

JSON-каталог имеет строгую проверку полей, дубликатов, пересечений контекстов и альтернатив талантов. Проверяются provenance, точные patch/class/spec/content, применимый season и дата проверки. SHA-256 фиксирует набор; digest каталога дополнительно включает версию механизма. Отчёт не меняет каталог и исходный снимок.

`GET /api/v1/characters/{region}/{realm}/{name}/analysis?content=general_pve|raid|mythic_plus` возвращает отчёт текущего разрешённого снимка; при отсутствии обязательного профиля действует обычный 202/job flow. Вторая транзакция чтения даёт согласованные snapshot/meta/report. Неизвестный контекст отклоняется до постановки задания. Существующие ограничения запросов и возраст данных сохраняются.

Миграция 0005 добавляет `analysis_results`. Ключ кеша: snapshot ID, digest каталога и контекст. Язык в ключ не входит: хранятся message keys и параметры, которые переводит UI. Load/Save заново проверяют current pointer, quarantine, сроки профиля/секций/идентичности; кеш не является правом на публикацию. Срок кеша не переживает ближайший переход свежести или допустимости исходных данных. Purge каскадирует результаты, GC очищает просроченные записи и результаты секций до обнуления их timestamps.

В web добавлена вкладка «Анализ», контексты, сводка, карточки результатов, раскрываемые доказательства и версия/происхождение правил. `Unknown` и `not_applicable` разделены; неприменимые карточки скрыты отдельным переключателем, неизвестные остаются видимыми. Отмена запросов и сверка snapshot/content не дают показать анализ другого персонажа или устаревшего контекста. Ошибка о недоступности/карантине очищает ранее показанный профиль.

## Демонстрация и реальный источник

В `fixture` доступен только явно синтетический набор `synthetic-1.0.0`, патч `synthetic-demo-v1`, класс 6/специализация 251, общий PvE. Все ID, матрицы зачарований, двухчастный комплект и эталон талантов вымышленные. Флаг `approved` означает согласованность локальной тестовой модели; он не подтверждает правила реальной игры. Фикстуры демонстрируют Unknown для головы, Warning для плаща, OK для запястий, Info для наблюдаемых частей комплекта и Unknown для неполных талантов.

Синтетические правила не применяются к Blizzard-данным. В реальном каталоге пока нет проверенных наборов; результаты там остаются `Unknown`. Для демонстрационного raid/mythic_plus тоже нет соответствующего набора, поэтому эти контексты честно показывают недоступность оценки. Выбор контекста анализа не означает реализации Mythic+/рейдового прогресса.

Чтобы включить реальные рекомендации, нужны подтверждённые актуальные источники, допустимость их использования, точный контекст и обезличенные входные fixtures с проверенными ожидаемыми результатами. Credentials Blizzard и live игровые данные на этом этапе не использовались.

- Regression tests исключают ложные выводы при частичных талантах, пересекающихся альтернативных узлах и неподдержанном предмете с известным set ID.
- Пять новых PostgreSQL-тестов кеша проверяют свежесть, сроки, текущий снимок, quarantine/purge, изоляцию digest/content, GC и конкурирующие записи.
- `npm run build --prefix web`: PASS. `npm test --prefix web`: 6/6 PASS.
- OpenAPI 3.1, 11 маршрутов: валиден. Контрактный HTTP-прогон через nginx: 22 ответа соответствуют схемам, включая контексты, равенство отчёта между RU/EN, Unknown без ruleset и безопасный 404.
- Docker-образы собраны; миграция 0005 применена без удаления прежних профилей. Демонстрационные профили обновлены обычным refresh.
- В браузере проверены контексты с правилом и без него, RU/EN, раскрытые доказательства и переключатель неприменимых проверок. На ширине 360 px основное содержимое и раскрытый JSON не создают горизонтального переполнения.
- После QA исправлено сохранение состояния раскрытой карточки при переключении фильтра и показ человеческого названия синтетического источника вместо технического URN. Повторная browser-проверка прошла.

GitHub Actions workflow подготовлен предыдущим этапом и включает эти пакеты через `./...`, web tests и контрактный прогон; удалённый CI не запускался. Нагрузочная квалификация и security-аудит production не выполнялись.
